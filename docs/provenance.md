# Provenance — Momentum

## Origin

- Original repository: `linear_clone`, a private reference build of a product-development marketing page.
- This is a change pass over that build, not a clean-room rebuild.
- Rebranded: name, copy, metadata, identifiers, logo, favicon and deployment URL.

## What changed

- All visible copy was rewritten for Momentum.
- Brand references were removed from code, metadata and documentation.
- Internal identifiers, file names and CSS classes were renamed from `linear-*` to `brand-*` or `product-*`.
- The brand mark, favicon and app icons were replaced with a new mark.

## Retained assets

The product imagery and customer logo strip under `public/media` were retained
from the original build by owner decision. They are not covered by the
repository license, and their use should be reviewed before commercial
distribution.
